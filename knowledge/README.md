# Documentação de engenharia

Cadastre textos aprovados pela tela Configurações → Conhecimento. A pasta não é lida automaticamente e não contém documentação do hospital. Não copiar dados de pacientes, segredos ou mapas reais para o repositório sem política adequada.

A ingestão futura de PDFs e embeddings é uma etapa distinta. Na versão 0.1.0, o RAG é lexical, sobre texto versionado e aprovado no banco.
